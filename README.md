# MetaShop.AO - Loja Online

## Bem-vindo à MetaShop.AO! 🎉

MetaShop.AO é uma plataforma de e-commerce moderna desenvolvida para oferecer uma experiência de compra excepcional aos clientes angolanos.

## Características

✨ **Interface Moderna e Responsiva**
- Design adaptável para todos os dispositivos
- Navegação intuitiva
- Carregamento rápido

🛍️ **Gestão de Produtos**
- Catálogo completo de produtos
- Informações detalhadas por produto
- Preços em Kwanza (Kz)

🛒 **Carrinho de Compras**
- Adicionar/remover produtos
- Persistência de dados com LocalStorage
- Contagem em tempo real

📱 **Responsivo**
- Funciona perfeitamente em desktop, tablet e mobile

## Estrutura do Projeto

```
MetaShop.AO/
├── index.html      # Página principal
├── styles.css      # Estilos e design
├── script.js       # Funcionalidades JavaScript
└── README.md       # Este arquivo
```

## Como Usar

1. Clone o repositório
2. Abra o arquivo `index.html` em seu navegador
3. Navegue pelos produtos
4. Adicione items ao carrinho
5. Continue explorando!
